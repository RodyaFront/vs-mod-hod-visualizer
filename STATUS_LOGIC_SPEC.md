# Спецификация статусов HOD Visualizer

## 1) Жажда (пороговый статус)
Источник:
- `EntityBehaviorThirst.CurrentThirst`
- `EntityBehaviorThirst.MaxThirst`

Расчет:
- `thirstPercent = (CurrentThirst / MaxThirst) * 100`

Логика отображения:
- `thirstPercent > 50`: статус не показывать.
- `20 <= thirstPercent <= 50`: показать статус `Жажда`.
- `0 < thirstPercent < 20`: показать статус `Сильная жажда`.
- `thirstPercent == 0`: показать критический статус `Вы умираете от дегидрации`.

Примечание:
- В HoD `CurrentThirst` ограничен диапазоном `0..MaxThirst`, поэтому кейс `<0` в рантайме не ожидается.

## 2) Охлаждение/Жара
Источник:
- `WatchedAttributes["hodCooling"]["totalCooling"]`
- (опционально) `WatchedAttributes["thirst"]["thirstRate"]` для вычисления фактического отклонения от базового расхода.

Логика отображения:
- `totalCooling < 0`: статус `Вам жарко`.
- `totalCooling > 0`: статус `Вам холодно`.
- `totalCooling == 0`: статус не показывать.

Tooltip-паттерн:
- Жара: `Потеря очков жажды увеличена на X% (из-за жары).`
- Холод: `Потеря очков жажды уменьшена на X% (из-за охлаждения).`

Где брать `X`:
- Вариант A (предпочтительный): вычислять по отклонению `ThirstRate` от базового thirst decay из конфига HoD.
- Вариант B: если точный коэффициент недоступен, показывать приближенное значение по `totalCooling`.

## 3) Перегруз жидкостями (обязательный статус)
Назначение:
- Явно объяснить игроку, почему он замедлен при переносе больших объемов жидкости.

Источники (технически):
- `EntityBehaviorLiquidEncumbrance` напрямую не пишет отдельный watched-флаг для UI.
- Состояние определяется через:
  - проверку инвентаря по логике HoD;
  - либо чтение итогового штрафа в `entity.Stats` (walkspeed modifier).

Логика отображения:
- Если активен штраф от liquid encumbrance: показать статус `Перегруз жидкостями`.
- Если штрафа нет: статус скрыт.

Tooltip:
- `Скорость передвижения снижена из-за перегруза жидкостями.`
- Дополнительно: `В ванильной игре такой штраф отсутствует.`

## 4) Штраф питательных веществ (опционально)
Источник:
- `EntityBehaviorThirst.NutritionDeficitAmount`

Логика отображения:
- `nutritionDeficitAmount > 0`: показать статус `Вода была с привкусом`.
- `nutritionDeficitAmount <= 0`: статус скрыт.

Tooltip:
- `Накопленный штраф пит. веществ: {value}.`

## Приоритеты отображения (предложение)
- Высокий: `Вы умираете от дегидрации`, `Перегруз жидкостями`.
- Средний: `Сильная жажда`, `Вам жарко`.
- Низкий: `Жажда`, `Вам холодно`, `Вода была с привкусом`.
