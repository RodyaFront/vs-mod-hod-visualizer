# HOD Visualizer Smoke Testing

## Цель

Быстро проверить, что `hodvisualizer` корректно подключается к `HydrateOrDiedrate` + `PlayerStatusStrip`, показывает статусы и не создает ошибок в логах.

## Предусловия

- Установлены и включены моды:
  - `playerstatusstrip`
  - `hydrateordiedrate`
  - `hodvisualizer`
- Сборка и деплой `hodvisualizer` выполнены в `Mods/hodvisualizer`.
- Сборка и деплой `playerstatusstrip` выполнены в `Mods/playerstatusstrip`.
- Клиент Vintage Story перезапущен после обновления модов.

## Быстрый pre-flight

1. Запустить мир в Survival.
2. Убедиться, что игра не падает на загрузке.
3. Проверить, что иконки статусов загружаются (нет пустых плейсхолдеров).
4. Проверить `client-main.log` на ошибки `hodvisualizer`/`playerstatusstrip`.

## Чеклист статусов

### 1) Жажда (tier-логика)

- [ ] При `>50%` гидратации статус `Жажда` не отображается.
- [ ] При `20-50%` отображается `Жажда`.
- [ ] При `<20%` отображается `Сильная жажда`.
- [ ] При `0%` отображается `Вы умираете от дегидрации`.

Pass критерий:
- переходы происходят только на ожидаемых порогах, без “дребезга” между tier.

### 2) Температура (жара/холод)

- [ ] В условиях жары отображается статус `Вам жарко`.
- [ ] В условиях охлаждения отображается статус `Вам холодно`.
- [ ] Tooltip у жары сообщает про увеличение потери жажды в `%`.
- [ ] Tooltip у холода сообщает про уменьшение потери жажды в `%`.

Pass критерий:
- одновременно не показываются `Вам жарко` и `Вам холодно`.

### 3) Перегруз жидкостями

- [ ] При переносе жидкости сверх порога появляется `Перегруз жидкостями`.
- [ ] Tooltip объясняет причину замедления.
- [ ] После снижения переносимого объема статус исчезает.

Pass критерий:
- статус коррелирует с реальным штрафом скорости, без зависания после снятия перегруза.

### 4) Штраф пит. веществ (опционально)

- [ ] При `nutritionDeficitAmount > 0` появляется `Вода была с привкусом`.
- [ ] Tooltip показывает текущее значение накопленного штрафа.
- [ ] При возврате к `0` статус пропадает.

Pass критерий:
- отображаемое число меняется согласно состоянию игрока.

## Негативные сценарии

- [ ] Отключить `hydrateordiedrate`: `hodvisualizer` не падает, просто не регистрирует рабочие статусы.
- [ ] Отключить `playerstatusstrip`: `hodvisualizer` не падает, пишет ожидаемое предупреждение в лог.
- [ ] Перезаход в мир: провайдер не дублируется, статусы не удваиваются.

## Логи и диагностика

Проверить после прогона:
- `client-main.log`
- `client-debug.log`

Недопустимо:
- исключения `hodvisualizer` в каждом тике;
- ошибки загрузки иконок `assets/hodvisualizer/textures/icons/*`;
- ошибки регистрации provider в `PlayerStatusStrip`.
